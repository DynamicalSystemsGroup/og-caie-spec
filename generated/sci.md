## The essentials

9 requirements: 7 verified by machine alone; 2 checked by machine for form, with the judgment itself made by a named person.

| ID | Name | Checked by | Statement |
|---|---|---|---|
| SCI-01 | DsoApprovedBeforeProbes | machine (shape S1) | The DSO release is versioned and approved by a named domain expert before any probe is derived. |
| SCI-02 | RequirementsDeclaredBeforeRuns | machine (shape S2) | Operational environment, requirement set, criteria and weights are declared before any probe run. |
| SCI-03 | CriteriaWellFormed | machine (shape S2) | Every acceptance criterion derives from a requirement, is verifiable (INCOSE GtWR v4 C7), and carries a weight greater than zero. |
| SCI-04 | ProbesDerivedAndChecked | machine (shape S3) | Every probe names the criteria it exercises, derives from the DSO release, and passed an automatic consistency check before any expert saw it. |
| SCI-05 | EvidenceFromNamedRuns | machine (shapes S4, S5) | Every evidence item was generated by a probe run against a named SUT version by a named operator. |
| SCI-06 | AttestationsWellFormed | machine (shape S6) for the form; human for the values of outcome, appropriateness and sufficiency | Every attestation names one criterion and one human assertor, is manual, carries an EARL outcome, appropriateness, sufficiency and the EPO step; passed or failed requires at least one piece of evidence (the closure rule: no evidence, no verdict). |
| SCI-07 | CoverageRecomputable | machine (shape S7 and queries/coverage.rq) | Coverage is computed by machine only over a conformant record, a criterion counts as covered only when it carries an attestation, and the number is the weighted share anyone can recompute. |
| SCI-08 | CoverageAndPerformanceKeptApart | machine (shape S7) | The report carries coverage and the outcome distribution as separate quantities; the distribution is over the covered criteria and sums to one. |
| SCI-09 | RecommendationTraceable | machine (shape S8) for the trace; human for the recommendation itself | Every recommendation is attributed to a person and traces to attestations, their evidence, the DSO release and the EPO step. |
