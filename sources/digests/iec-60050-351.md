# IEC 60050-351:2013, International Electrotechnical Vocabulary, Control technology — digest

Source: `src:iec-60050-351`, cite-only. Transcribed from Electropedia (publication date 2013-11) on 2026-09-06; the quotes were verified by Z on 2026-09-06 (rulings sheet 02). Ruling R-13.

| IEV ref | Term | Verbatim (English) |
|---|---|---|
| 351-41-08 | state variable | element of a vector x(t) in a system with the differential equations ẋ(t) = f[x(t), u(t)] state equation, v(t) = g[x(t), u(t)] output equation ... Note 1 to entry: In case of discrete-time variables the describing equations are xi+1 = f (xi, ui) state equation vi = g (xi, ui) output equation |
| 351-41-09 | state space | space defined by the state variables as axes of a vector space, in which every vector represents a state of the system |
| 351-41-10 | trajectory | representation of the solution x(t) of the state equation as connecting line of the ends of the vector x(t) in state space with time as parameter |
| 351-45-07 | identification of a system | procedures for creating a mathematical model representing the static and dynamic behaviour of a system |
| 351-47-01 | closed-loop control, feedback control | process whereby one variable quantity, namely the controlled variable is continuously or sequentially measured, compared with another variable quantity, namely the reference variable, and influenced in such a manner as to adjust to the reference variable |
| 351-47-28 | state-feedback control | closed-loop control with proportional feedback of a complete set of measured or estimated state variables |
| 351-47-29 | output-feedback control | closed-loop control with feedback of the measured output variables only |
| 351-47-31 | observer | system for complete reconstruction of the state of a controlled system from measured input and output variables, using a model of the controlled system |
| 351-47-44 | parameter sensitivity | amount of variation of essential system properties, for example eigenvalues of the differential equation describing the system, in relation to variation of system parameters |
| 351-49-01 | controlled system | functional unit which is to be influenced according to the control task |
